## What each release asset is built from

| Asset | Built from |
|---|---|
| `riscos-gcc16-cross-16.2.0-24-x86_64-linux.tar.xz` | GCC 16.2.0 + binutils 2.45.1 + this repository's `recipe/` and `modkit/` (the module kit, installed by `install-modkit.sh`; [BUILDING.md](docs/BUILDING.md), steps 2 to 5), UnixLib headers and libraries from the GCCSDK sources and the runtime packages |
| `Gcc16_16.2.0-24_arm.zip` | GCC 16.2.0, binutils 2.45.1 and make 4.4.1 plus the patches in `recipe/` and the module kit of `modkit/` (the native build: step 7), cross-built with the cross compiler above |
| `Gcc16SelfTest_16.2.0-24_arm.zip` | `recipe/gcc-16.2.0-riscos/tests/selftest` (published as [`tests/selftest`](tests/selftest)), packed by `make-selftest-package.py` |
| `SharedLibs-C-armeabihf_16.2.0-15_arm.zip` | UnixLib 5.0 (svn r7800) + `patches-unixlib/` built with the cross compiler; the loader, `libgcc_s` and `libdl` from the GCCSDK package |
| `SharedLibs-C++-armeabihf_16.2.0-6_arm.zip`, `SharedLibs-Fortran-armeabihf_16.2.0-2_arm.zip` | libstdc++ and libgfortran of GCC 16.2.0 built by the cross compiler |
| `SharedULibFix_1.16-vforkfix3_arm.zip` | `module/sul.s` of the UnixLib snapshot with `patches-unixlib/unixlib-sul-vfork-child-*.patch`, assembled by `build-sul.sh` with GCCSDK 10.2.0's tool chain (step 6 of [BUILDING.md](docs/BUILDING.md)); the programs and Obey files are `recipe/gcc-16.2.0-riscos/sulfix`, built with the cross compiler |

The package files are generated by `recipe/gcc-16.2.0-riscos/scripts/make-*-package.py`; their metadata (maintainer, licence, copyright text) comes from `pkgmeta.py`.

## Sources that tests and recipes fetch (not shipped)

These are downloaded by the scripts named, from the owners, and are not in the releases or in this repository: [OSLib](docs/OSLIB.md), [DeskLib32](docs/DESKLIB.md), [FlexLib and SFLib](docs/FLEXLIB.md), [RUfl](docs/RUFL.md), [NetSurf](docs/NETSURF.md) and its libraries, and the RISC OS Open sources named above. One more is a test of the module kit: [Sunfish](https://github.com/ajw498/NFS), Alex Waugh's NFS client filing system (MIT licence), is built unmodified from revision `afa0a8c` by `tests/sunfish/build-sunfish.sh`.

## Corresponding source

For every binary on the releases page, the corresponding source is: the unmodified tarballs above (attached to the release), this repository at the release's tag, and, for the UnixLib part, the attached UnixLib snapshot (unpack it into an empty directory and run `recipe/gcc-16.2.0-riscos/scripts/apply-unixlib-patches.sh <that directory>` to get the patched source of the released library). The dynamic loader, `libgcc_s` and `libdl` in the C runtime package are the unchanged files of GCCSDK's own package, whose sources are GCC 10.2.0 and the GCCSDK svn named in the table.
The licences are in [LICENSES.md](LICENSES.md).
